Embedding Settings

Manage local vector embeddings strictly separate from chat/generation models

Embedding Isolation: Embedding models convert code into dense mathematical vectors stored in Qdrant. They are strictly separate from chat/generation models.
Local Ollama is the default local embedding provider.
Default: nomic-embed-text (or all-minilm, mxbai-embed-large)
Must match model output (e.g. 768 for nomic-embed-text, 384 for all-minilm, 1024 for mxbai).
Number of chunks embedded per batch request.
Warning: Changing the embedding model or vector dimensions requires rebuilding existing Qdrant vector collections.
